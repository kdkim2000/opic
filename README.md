# OPIc 연습 (Eva Practice)

OPIc 말하기 시험을 폰으로 준비하는 학습 앱(PWA)과, 그 콘텐츠를 만드는 도구 모음입니다.
Eva의 질문을 듣고 → 내 목소리로 답하고 → 스크립트·모델 답변과 비교하는 과정을 **23세트 344문항**으로 반복할 수 있습니다.
요구사항과 설계는 [PRD.md](PRD.md)를 보세요.

## 한눈에 보기

홈 화면에서 목적에 맞는 모드를 고릅니다.

| 모드 | 언제 쓰나요? | 하는 일 |
| --- | --- | --- |
| **Survey 모드** | 시험 첫 화면이 낯설 때 | 실제 Background Survey(7문항)를 내 시나리오대로 빠르고 정확하게 선택하는 연습. 4~7번 합계 12개 이상 규칙까지 그대로 연습합니다. 다른 콘텐츠에는 영향이 없습니다. |
| **기초 모드** | 영어가 자꾸 막힐 때 | 자주 쓰는 **표현 158개**(14종류)와 **필러 36개**(6종류)를 듣고 따라 말하며 입에 붙입니다. **필러 챌린지**로 말이 끊기지 않는지 측정합니다. |
| **연습 모드** | 스토리를 자연스럽게 만들어 말하고 싶을 때 | 주제별로 묶인 문항을 **키워드(동사·명사)만 보고** 영어식으로 이야기를 이어 말합니다. 난이도를 올려 가며 키워드를 줄입니다. |
| **학습 모드** | 모범 답안을 익히고 싶을 때 | 질문 → 스크립트 → 모델 답변(배속·반복) → 내 녹음 → 비교. 한 문항씩 천천히 쉐도잉합니다. |
| **실전 모드** | 시험처럼 연습하고 싶을 때 | 세트 하나(15문항)를 처음부터 끝까지, 스크립트 없이 질문→녹음을 이어서 합니다. |
| **어려움 모음** | 약한 문항만 복습할 때 | "어려움"으로 표시한 문항만 모아 다시 연습합니다. |

모든 녹음과 학습 기록은 **내 폰(브라우저) 안에만** 저장됩니다. 서버로 전송되지 않습니다.

## 빠른 시작

### 1. 앱 열기
배포된 주소(GitHub Pages)를 폰 브라우저로 엽니다. 폰에서 녹음하려면 HTTPS가 필요하므로 배포 주소를 쓰세요.
(내 PC에서 직접 돌려 보려면 [콘텐츠 구성과 수정](#콘텐츠-구성과-수정-만드는-사람용)의 "로컬 실행"을 보세요.)

### 2. 홈 화면에 설치 (권장)
- **Android Chrome**: 메뉴(⋮) → "홈 화면에 추가"
- **iPhone Safari**: 공유 버튼 → "홈 화면에 추가"

설치하면 앱처럼 전체 화면으로 열립니다. 지원 환경은 iOS Safari 16+, Android Chrome 최신, 데스크톱 Chrome입니다.

### 3. 마이크 허용
처음 녹음할 때 마이크 권한을 **허용**해 주세요. 거부했다면 브라우저(또는 폰) 설정의 사이트 권한에서 마이크를 허용으로 바꾸세요.

### 4. 첫 연습 해 보기 (3분)
1. 홈에서 **기초 모드** → "의견·생각 말하기" → 첫 표현 카드에서 ▶를 눌러 듣고 따라 말합니다.
2. 홈으로 돌아가 **학습 모드**로 가장 위(최신 문제)의 세트를 열고 Q1~Q3을 해 봅니다.
3. 막히는 문항에는 "어려움"을 눌러 두세요. 나중에 **어려움 문항 모아 연습**에서 모아 볼 수 있습니다.

## OPIc 준비 추천 순서

OPIc은 같은 주제를 **한 편의 이야기**로 1~2분 동안 끊김 없이 말하는 시험입니다. 아래 순서를 추천합니다(시험 날짜에 맞춰 줄이거나 늘려도 됩니다).

| 단계 | 목표 | 어떤 모드로? | 하루 분량(예시) |
| --- | --- | --- | --- |
| 0. 시험 화면 익히기 | Background Survey를 막힘없이 고르기 | **Survey 모드** (가이드 → 시험처럼) | 5분 (시험 전 수시로) |
| 1. 입 풀기 | 기본 표현·필러를 입에 붙이기 | **기초 모드** 표현 카테고리 1~2개 + 필러 그룹 1개 | 15분 |
| 2. 이야기 만들기 | 키워드로 스토리 이어 말하기 | **연습 모드**에서 Survey 주제부터 (집·카페·음악·영화·공원·해변·여행) | 20분 |
| 3. 돌발·롤플레이 대비 | 선택하지 않은 주제와 전화 롤플레이에 익숙해지기 | **연습 모드**의 "돌발 주제"와 "롤플레이" | 20분 |
| 4. 모범 답안 쉐도잉 | 문장 리듬과 발음 익히기 | **학습 모드**: 모델 답변 0.9배속 반복 → 내 녹음과 비교 | 20분 |
| 5. 실전 감각 | 시간·긴장감에 적응하기 | **실전 모드**로 세트 1개 완주 → 녹음 다시 듣기 | 30분 (주 2~3회) |
| 6. 약점 보완 | 막혔던 문항 반복 | **어려움 문항 모아 연습** + 필러 챌린지 | 15분 |

시험이 가까우면 **Survey 모드를 먼저 한 번 훑고**, 매일 **기초 모드 5분(워밍업) → 연습/학습 모드 → 어려움 모음 5분(복습)** 순서로 하면 부담 없이 이어 갈 수 있습니다.

> 팁: 답변 길이는 **60~90초**, 8~12문장이 목표입니다. 스크립트를 통째로 외우지 말고, **굵은 표현(뼈대)** 과 키워드만 기억해서 매번 다르게 말해 보세요.

## 모드별 사용법

### 홈 화면
- 맨 위: **연습 모드**, **기초 모드** 입구
- **최신 문제 (opic16~30)** 세트 카드: 진행 막대와 [실전 모드] [학습 모드] 버튼
- **이전 문제 (opic1~8)**: 접혀 있습니다. 눌러서 펼칩니다.
- 맨 아래: **어려움 문항 모아 연습 (n)**

### Survey 모드 — 시험 첫 화면 연습
홈 → **Survey 모드**

시험이 시작되면 가장 먼저 만나는 Background Survey를 그대로 연습합니다. **이 화면의 선택은 앱의 다른 콘텐츠(문항·주제·키워드)를 바꾸지 않습니다.** 선택을 빠르게, 틀리지 않게 하는 연습일 뿐입니다.

- **내 시나리오**: 기본값은 일경험 없음 / 학생 아니오 / 홀로 거주 / 여가 8개 / 취미 1개 / 운동 3개 / 여행 2개입니다. **내 시나리오 수정**에서 내 상황에 맞게 바꿀 수 있습니다. 여가처럼 개수만 정하고 항목은 자유로 둘 수도 있습니다.
- **가이드 연습**: 내 시나리오 항목에 ★ 힌트가 보이고, 고를 때마다 맞음(✔)/시나리오에 없음(⚠)이 바로 표시됩니다.
- **시험처럼 연습**: 힌트 없이 풀고 타이머가 돌아갑니다. 제출하면 질문별로 빠뜨린 항목, 잘못 고른 항목, 개수 차이를 알려 주고 이전 기록과 비교합니다. **틀린 질문만 다시** 풀 수 있습니다.
- 화면 구성은 실제 설문처럼 **1쪽(1~3번, 단일 선택) → 2쪽(4~7번, 복수 선택)** 입니다. 2쪽에는 선택 개수 카운터가 있고, **4~7번 합계가 12개 이상이어야 다음으로 넘어갑니다.**
- 한글 항목 아래에 영어 표현이 함께 나옵니다. 시험에서 "You indicated in the survey that you …"로 나오는 말과 연결해 두세요.
- 실제 시험 시기에 따라 항목·조건이 다를 수 있습니다.

### 기초 모드 — 표현과 필러를 입에 붙이기
홈 → **기초 모드**

**① 기본 표현 (14종류)** — 의견, 이유, 과거 경험 시작, 반전, 감정, 비교, 묘사, 습관, 선호, 질문·요청, 문제·사과, 추측, 마무리, 감사 등 기능별로 비슷한 표현끼리 묶여 있습니다. 종류를 고르면 표현 목록이 나오고 하나를 열면 4단계 카드가 나옵니다.

| 단계 | 하는 일 |
| --- | --- |
| ① 듣기 | 표현과 예문을 ▶로 듣습니다. 속도 0.75 / 0.9 / 1.0 선택 |
| ② 따라 말하기 | 문장을 고르고 3회 또는 5회 자동 반복. 소리가 끝나면 같은 길이의 빈 시간에 따라 말합니다. |
| ③ 바꿔 말하기 | 한글 뜻(상황)만 보고 이 표현으로 직접 영어 문장을 말해 본 뒤 정답 예문을 듣습니다. |
| ④ 섞어 말하기 | 같은 종류의 표현을 한글 뜻만 보고 순서 없이 말합니다. "알았어요 / 다시"로 스스로 평가합니다. |

"알았어요 (마스터 표시)"를 누르면 ✔가 표시되고 진행률에 반영됩니다. 목록의 **섞어 말하기** 버튼으로 한 종류를 한꺼번에 복습할 수 있습니다.

**② 필러 연습 (6종류)** — 말이 막힐 때 시간을 버는 말입니다. 시간 벌기(Well, / Let me think), 화제 이음(So, / And then), 솔직·강조(Honestly, / To be honest), 정정·보충(I mean, / You know), 예시·설명(For example, / Basically), 마무리(In the end, / Long story short). 카드에서 언제 쓰는지 설명을 읽고 듣기·따라 말하기를 합니다.

**필러 챌린지** — 말이 끊기지 않는 연습입니다.
1. Survey 주제의 질문 하나가 무작위로 나옵니다. 시작·이음·마무리·막힐 때 쓸 필러 칩을 참고하세요.
2. **시작**을 누르면 3-2-1 후 녹음이 시작되고, 45초 동안 말합니다(일찍 끝내도 됩니다).
3. 결과: **총 시간 / 말한 비율 / 최장 침묵 / 2초 이상 침묵 횟수**. 3초 이상 막혔다면 "막힐 때 쓰는 표현"을 안내합니다.
4. 내 녹음 듣기, 모델 답변 듣기, 다시 도전, 다른 질문으로 반복합니다. (챌린지 녹음은 저장되지 않습니다.)

> 침묵 측정은 마이크 소리 크기로 계산하는 대략적인 값입니다. 조용한 곳에서 같은 환경으로 비교해 보세요.

### 연습 모드 — 키워드로 이야기 이어 말하기
홈 → **연습 모드**

주제가 **① 자기소개 ② Survey 주제 ③ 돌발 주제 ④ 롤플레이** 순으로 나옵니다.
- **Survey 주제**: 시험 설문에서 고르는 주제 (집·카페·음악 감상·영화·콘서트·공원·해변·국내여행·해외여행)
- **돌발 주제**: 선택하지 않아도 나올 수 있는 주제를 비슷한 것끼리 묶었습니다 (건강, 음식, 기술, 날씨·자연, 일상, 모임·명절, 직업, 생활 서비스, 환경·사회)
- **롤플레이**: 여행, 서비스·쇼핑, 약속·계획, 직장·생활 문제

주제를 열면 여러 세트의 같은 주제 문항이 모여 있습니다. 문항 카드 사용법:
1. **▶ 질문 듣기**로 질문을 듣습니다.
2. **스토리 키워드**를 봅니다.
   - **장면 단계(①②③)**: 영어 어순으로 짧게 적힌 이야기의 뼈대입니다. 순서대로 이어 말하면 답변이 됩니다.
   - **동사 칩 / 명사 칩**: 이야기에 쓸 단어들. 쓴 단어는 탭해서 표시합니다.
3. 난이도 버튼으로 힌트를 줄여 갑니다.

| 난이도 | 보이는 힌트 |
| --- | --- |
| Lv1 | 장면 단계 + 동사 + 명사 |
| Lv2 | 동사 + 명사 |
| Lv3 | 명사만 (나머지는 상상해서!) |

4. **● 녹음**으로 60~90초 동안 말하고 정지합니다.
5. **확인하기**: 스크립트 보기, 모델 답변 듣기로 비교합니다.
6. **자기 평가**(어려움 / 보통 / 완료)를 누르고 **다음 ›** 으로 이동합니다. **처음부터 연속 연습**을 누르면 주제 안 문항을 차례로 풉니다.

### 학습 모드 — 모범 답안으로 쉐도잉
홈 → 세트 카드의 **[학습 모드]** → 문항 선택 (그룹 옆 **그룹 연속 연습**으로 비슷한 문항을 이어서 연습)

한 문항 화면의 구성:
1. **질문**: 텍스트를 보고 ▶로 듣기 (횟수 제한 없음)
2. **내 답변 스크립트**: 굵은 표현이 뼈대입니다. **가리기**를 누르면 굵은 표현만 남기고 가려서 기억을 시험합니다. 아래 칩은 핵심 표현입니다.
3. **모델 답변**: 재생 / ⏪10 / 10⏩ / 속도(0.75·0.9·1·1.15) / 반복(1회·3회·무한). 처음엔 0.9배속으로 따라 말하는 것을 추천합니다.
4. **내 녹음**: ● 녹음 → ■ 정지. 문항당 최근 5개가 저장되고 ▶ 재생, ⬇ 다운로드, 🗑 삭제가 가능합니다. **모델 ↔ 내 녹음 번갈아 듣기**로 차이를 비교하세요.
5. **자기 평가**: 어려움 / 보통 / 완료

### 실전 모드 — 시험처럼 한 세트 완주
홈 → 세트 카드의 **[실전 모드]** → **시작**

1. 마이크 권한을 허용하고 시작합니다.
2. Eva의 질문이 재생됩니다. 끝나면 **3초 카운트**가 돌고 자동으로 녹음이 시작됩니다.
3. 질문 **다시 듣기는 문항당 1회**만 가능합니다(카운트다운 중에만 누를 수 있어요).
4. 다 말했으면 **답변 끝**을 누르면 다음 문항으로 넘어갑니다. 목표 시간은 60~90초이며 강제로 끊기지 않습니다.
5. 끝나면 문항별 녹음 시간이 나옵니다. 각 문항을 눌러 학습 모드에서 내 녹음을 다시 듣고 모델 답변과 비교하세요.

스크립트와 모델 답변은 실전 중에는 보이지 않습니다. 중간에 나가면 진행 중인 문항은 저장되지 않고 이미 끝낸 문항의 녹음만 남습니다.

### 어려움 문항 모아 연습
어느 모드에서든 문항의 **어려움** 버튼을 누르면 홈 맨 아래 **어려움 문항 모아 연습 (n)** 에 모입니다. 한 번 더 연습한 뒤 "보통/완료"로 바꾸면 목록에서 빠집니다.

## 자주 묻는 질문

**녹음 버튼을 눌러도 안 돼요.** 마이크 권한을 허용했는지, 배포 주소(HTTPS)로 접속했는지 확인하세요. 인앱 브라우저(메신저 등)에서는 녹음이 막힐 수 있으니 Safari/Chrome에서 여세요.

**소리가 안 나요.** 폰이 무음 모드가 아닌지, 미디어 볼륨을 확인하세요. 처음 한 번은 화면의 재생 버튼을 직접 눌러야 소리가 납니다(브라우저 정책).

**비행기·지하철 등 오프라인에서도 되나요?** 화면 틀은 캐시되지만 **음원은 오프라인 재생이 되지 않습니다**(2차 기능 예정). 접속 가능한 때 미리 열어 두세요.

**기록이 사라졌어요.** 기록과 녹음은 브라우저 안에만 있어서 사이트 데이터를 지우면 함께 삭제됩니다. 중요한 녹음은 ⬇로 파일을 저장해 두세요. (내보내기/가져오기는 예정)

**다른 폰에서 이어서 할 수 있나요?** 계정과 동기화가 없어서 기기마다 기록이 따로입니다.

**아이폰에서 녹음 파일 형식이 달라요.** iPhone은 m4a, 안드로이드/크롬은 webm으로 저장됩니다(자동 선택).

### 로컬 실행

```bash
pip install edge-tts                  # MP3를 새로 만들 때만 필요 (빌드에는 불필요)

python tools/build_data.py            # 23세트 344문항 + 키워드 + 기초 모드 데이터 생성, 음원 복사

```

`app/audio/`, `app/data/*.json`은 빌드 산출물이라 git에 올리지 않습니다(CI가 매번 새로 만듭니다).

## 배포 (GitHub Actions → GitHub Pages)

`main`(또는 `master`) 브랜치에 푸시하면 [.github/workflows/deploy.yml](.github/workflows/deploy.yml)이 자동으로 실행됩니다.

```text
push → build: python tools/build_data.py   (questions.json·basics.json 생성, 음원을 app/audio 로 복사)
     → 점검: 문항 수와 음원(질문·답변·기초 모드) 누락 검사 (누락이 있으면 배포 중단)
     → app/ 폴더를 Pages 아티팩트로 업로드 → deploy
```

- 빌드에 외부 패키지가 필요 없습니다.
- 음원 원본(`test/mp3`, `ansewer/mp3`, `test2/mp3`, `answer2/mp3`, `basics/mp3`)은 **저장소에 커밋**해야 합니다. 빠지면 점검 단계에서 실패합니다.
- 앱은 상대 경로만 사용하므로 `https://<계정>.github.io/<저장소>/` 같은 하위 경로에서도 동작합니다.

### 최초 1회 설정
1. GitHub에 저장소를 만들고 푸시합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
3. **Actions** 탭에서 워크플로 실행이 끝나면 Pages 주소가 표시됩니다. 폰에서 그 주소로 접속해 "홈 화면에 추가"를 하세요.

### 앱이 예전 화면이에요
앱을 업데이트했는데 그대로라면 브라우저를 완전히 닫았다가 다시 열거나, 홈 화면 앱을 삭제하고 다시 추가하세요(서비스 워커 캐시 갱신).

## 개인정보와 공개 범위

- 녹음과 학습 기록은 기기 밖으로 나가지 않습니다. 분석 도구나 외부 요청도 없습니다.
- 답변 스크립트는 이름·회사·거주지·가족 정보를 뺀 **일반적인 내용**으로 작성되어 있습니다. 내 실제 이야기로 바꿔 쓸 때는 공개 저장소·공개 사이트에 올라간다는 점을 고려하세요.
- GitHub Pages 사이트는 **저장소가 비공개여도 주소를 아는 누구나 접근할 수 있습니다**(Enterprise 플랜 제외). 비밀번호 등 접근 제한이 필요하면 Netlify/Cloudflare Pages 같은 호스팅을 쓰세요.
- 저장소를 공개하기 전에는 git **히스토리**에 예전 개인정보가 남아 있지 않은지 확인하세요. 파일을 고쳐도 이전 커밋에는 남습니다.
