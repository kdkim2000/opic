## 2. 서비스 카탈로그

| SC-ID | 서비스명 | 카테고리 | 연관 요구사항 ID | 설명 | 우선순위 |
|:---|:---|:---|:---|:---|:---:|
| SC-001 | 회원관리서비스 | 사용자관리 | FR-001, FR-002 | 가입·로그인·인증, 학습 프로필(목표 등급·시험일·관심 주제) | 높음 |
| SC-002 | 콘텐츠서비스 | 콘텐츠 | FR-003, FR-007, FR-012 | 질문 은행, 모범 답안·스크립트, 관리자 콘텐츠 관리 | 높음 |
| SC-003 | 답변연습서비스 | 기타(학습) | FR-004, FR-005 | 질문 연습(녹음·텍스트 답변), 모의고사, 답변 이력·녹음 삭제 | 높음 |
| SC-004 | AI피드백서비스 | 기타(AI) | FR-006 | 음성 전사(STT), AI 채점·피드백, 사용량 제한 | 높음 |
| SC-005 | 학습관리서비스 | 기타(학습) | FR-010, FR-011 | 학습 계획 생성·조정, 진도·성취 대시보드 | 중간 |
| SC-006 | 복습서비스 | 기타(학습) | FR-008, FR-009 | 핵심 표현 카드, 간격 반복 복습 스케줄링 | 낮음 |

## 3. 서비스별 상세 카드

#### SC-001 회원관리서비스
- **도메인**: 사용자관리
- **핵심 기능**: FR-001, FR-002
- **관련 UC**: UC-001, UC-002, UC-003
- **주요 액터**: 학습자
- **주요 데이터**: 사용자 계정, 학습 프로필
- **연계 서비스**: 전 서비스 (인증 세션 제공), SC-005 (목표 등급·시험일 제공)
- **릴리즈**: v1.0

#### SC-002 콘텐츠서비스
- **도메인**: 콘텐츠
- **핵심 기능**: FR-003, FR-007, FR-012
- **관련 UC**: UC-004, UC-007, UC-013
- **주요 액터**: 학습자, 관리자
- **주요 데이터**: 질문, 모범 답안, 핵심 표현 (DR-001)
- **연계 서비스**: SC-003 (연습 대상 질문 제공), SC-006 (표현 원천 제공), SC-001 (관심 주제 기반 추천)
- **릴리즈**: v1.0 (FR-003, FR-007), v2.0 (FR-012, MVP는 시드 데이터로 대체)

#### SC-003 답변연습서비스
- **도메인**: 기타(학습)
- **핵심 기능**: FR-004, FR-005 (FR-005는 SC-004와 연계)
- **관련 UC**: UC-005, UC-008, UC-014 (SR-004·DR-004 지원)
- **주요 액터**: 학습자
- **주요 데이터**: 답변 이력, 음성 파일 (DR-002, DR-004)
- **연계 서비스**: SC-002 (질문 조회), SC-004 (전사·채점 요청), SC-005 (학습 이력 제공)
- **릴리즈**: v1.0 (FR-004), v1.1 (FR-005)

#### SC-004 AI피드백서비스
- **도메인**: 기타(AI)
- **핵심 기능**: FR-006
- **관련 UC**: UC-006 (UC-005·UC-008에서 호출)
- **주요 액터**: 학습자, AI 채점 서비스(LLM), 음성 인식 서비스(STT)
- **주요 데이터**: 전사 텍스트, 점수·코멘트 (DR-002)
- **연계 서비스**: SC-003 (답변 수신·결과 반환), 외부 LLM/STT API (IR-001, IR-002)
- **비고**: 일일 제출 한도(CR-004)와 응답시간 30초(PR-002) 관리 주체
- **릴리즈**: v1.0

#### SC-005 학습관리서비스
- **도메인**: 기타(학습)
- **핵심 기능**: FR-010, FR-011
- **관련 UC**: UC-011, UC-012
- **주요 액터**: 학습자, 시스템 스케줄러
- **주요 데이터**: 학습 계획, 진도 통계 (DR-003)
- **연계 서비스**: SC-001 (프로필), SC-003 (답변 이력·점수), SC-006 (복습 일정 반영)
- **릴리즈**: v1.1

#### SC-006 복습서비스
- **도메인**: 기타(학습)
- **핵심 기능**: FR-008, FR-009
- **관련 UC**: UC-009, UC-010
- **주요 액터**: 학습자, 시스템 스케줄러
- **주요 데이터**: 표현 카드, 복습 주기 (DR-003)
- **연계 서비스**: SC-002 (표현·모범 답안), SC-005 (일정 통합)
- **릴리즈**: v2.0

## 4. 서비스 간 연계도 (텍스트)

```
[학습자/관리자]
      │
      ▼
 SC-001 회원관리 ──(인증 세션/프로필)──▶ 모든 서비스
      │
      ▼
 SC-002 콘텐츠 ──(질문)──▶ SC-003 답변연습 ──(답변)──▶ SC-004 AI피드백 ──▶ [LLM API] / [STT API]
      │  ▲                     │  ▲                         │
      │  └──(모범 답안)────────┘  └────────(점수·코멘트)────┘
      │                        │
      │ (표현)                 │ (답변 이력·점수)
      ▼                        ▼
 SC-006 복습 ◀──(복습 일정)──▶ SC-005 학습관리
```
