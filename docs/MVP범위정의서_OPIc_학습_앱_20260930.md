## 2. 가치 vs 복잡도 매트릭스

```
           │  고복잡도  │  저복잡도
───────────┼───────────┼──────────
 고가치     │  계획 필요 │  Quick Win ← MVP 우선
───────────┼───────────┼──────────
 저가치     │   제외     │  Nice-to-have
```

- **Quick Win** (고가치 + 저복잡도): FR-001, FR-002, FR-003, **FR-007**
- **계획 필요** (고가치 + 고/중복잡도): FR-004, FR-006, FR-005 (FR-006은 MVP 핵심이므로 가장 먼저 기술 검증)
- **Nice-to-have** (저복잡도): FR-008
- **제외**: 발음·억양 정밀 분석, 네이티브 앱

## 3. MVP 구성 (v1.0)

> Must 전체 + Quick Win Should 포함

| 기능 | 분류 | 우선순위 |
|:---|:---:|:---:|
| FR-001 회원 가입/로그인 | Must | 1 |
| FR-002 학습 프로필 설정 | Must | 2 |
| FR-003 질문 은행 조회 | Must | 3 |
| FR-004 질문 연습 | Must | 4 |
| FR-006 AI 답변 채점·피드백 | Must | 5 |
| FR-007 모범 답안·스크립트 학습 | Should (Quick Win) | 6 |

**MVP 핵심 흐름:** 가입 → 목표 설정 → 질문 선택 → 녹음/텍스트 답변 → AI 피드백 → 모범 답안과 비교

**MVP 함께 적용할 비기능 요구사항:** SR-001~SR-004 (인증·접근통제·음성 동의/삭제), PR-002 (피드백 30초), CR-001 (자체 제작 콘텐츠), CR-004 (AI 일일 사용 횟수 제한)

> 참고: 기능 수(6개)는 권장 범위(10~20개)보다 적으나, 1인/소규모 개발과 AI 채점 기술 검증을 우선하는 최소 구성이다. 모의고사(FR-005)를 v1.0에 넣을지는 일정에 따라 조정 가능하다.
