## 1. 메뉴 구조 (계층 트리)

```
[공개 영역]
 ├─ SCR-001 로그인
 ├─ SCR-002 회원 가입
 └─ SCR-003 비밀번호 재설정

[학습자 영역]
 GNB
 ├─ 홈
 │    └─ SCR-005 홈
 ├─ 연습                                   (SC-002, SC-003, SC-004)
 │    ├─ 질문 은행
 │    │    ├─ SCR-006 질문 은행 목록
 │    │    ├─ SCR-007 질문 연습 (답변 제출)        ← 질문 선택 시
 │    │    ├─ SCR-008 AI 피드백 결과              ← 제출 후
 │    │    └─ SCR-009 모범 답안 비교              ← 피드백에서 이동
 │    └─ 내 답변 이력
 │         └─ SCR-018 내 답변 이력 (녹음·답변 삭제)
 ├─ 모의고사                                (SC-003)  [v1.1]
 │    ├─ SCR-010 모의고사 시작
 │    ├─ SCR-011 모의고사 진행                    ← 시작 시
 │    └─ SCR-012 모의고사 결과                    ← 종료 시
 ├─ 학습 관리                               (SC-005)  [v1.1]
 │    ├─ SCR-013 학습 계획
 │    └─ SCR-014 진도 대시보드
 ├─ 복습                                    (SC-006)  [v2.0]
 │    ├─ SCR-015 표현 카드 목록
 │    ├─ SCR-016 표현 카드 등록·수정              ← 목록에서 이동
 │    └─ SCR-017 복습 학습
 └─ 내 정보                                 (SC-001)
      └─ SCR-004 학습 프로필 설정               ← 가입 직후 온보딩에도 사용

[관리자 영역]                                (SC-002)  [v2.0]
 GNB
 └─ 콘텐츠 관리
      ├─ SCR-019 질문 관리 목록
      ├─ SCR-020 질문·모범 답안 등록/수정          ← 목록에서 이동
      └─ SCR-021 핵심 표현 관리
```
