# cat: guess | 추측·가능성 말하기
## guess-01
- pattern: I guess ~
- meaning: ~인 것 같아요 (가볍게 추측)
- when: 확신 없이 편하게 내 생각을 말할 때
- ex: I guess it's because I'm tired. | 아마 피곤해서인 것 같아요.
- ex: I guess I like it more than I thought. | 생각보다 더 좋아하는 것 같아요.
- ex: I guess so. | 그런 것 같아요.
## guess-02
- pattern: I think ~, but I'm not sure.
- meaning: ~인 것 같은데, 확실하진 않아요
- when: 기억이나 정보가 불확실할 때
- ex: I think it was in May, but I'm not sure. | 5월이었던 것 같은데 확실하진 않아요.
- ex: I think it's near the station, but I'm not sure. | 역 근처인 것 같은데 확실하진 않아요.
## guess-03
- pattern: It seems like ~
- meaning: ~인 것 같아요 / ~처럼 보여요
- when: 상황을 보고 판단해서 말할 때
- ex: It seems like everyone enjoyed it. | 다들 즐거워한 것 같아요.
- ex: It seems like it's getting more popular. | 점점 더 인기가 많아지는 것 같아요.
- ex: It seems like a good deal. | 괜찮은 거래인 것 같아요.
## guess-04
- pattern: It looks like ~
- meaning: ~할 것 같아요 / ~처럼 보여요
- when: 눈에 보이는 단서로 추측할 때
- ex: It looks like it's going to rain. | 비가 올 것 같아요.
- ex: It looks like we're going to be late. | 우리 늦을 것 같아요.
## guess-05
- pattern: Maybe ~
- meaning: 어쩌면 ~
- when: 가능성 하나를 가볍게 던질 때
- ex: Maybe I should try something new. | 어쩌면 새로운 걸 해 봐야 할지도 몰라요.
- ex: Maybe it's just me. | 어쩌면 저만 그런지도 몰라요.
- ex: Maybe next time. | 다음에 하면 되겠죠.
## guess-06
- pattern: I'd say ~
- meaning: ~라고 할 수 있겠네요 (대략 말해서)
- when: 정확하진 않지만 대략 판단해서 답할 때
- ex: I'd say it's about twenty minutes. | 대략 20분 정도예요.
- ex: I'd say it was one of my best trips. | 최고의 여행 중 하나였다고 할 수 있어요.
## guess-07
- pattern: ~ probably ...
- meaning: 아마 ...할 거예요
- when: 꽤 높은 가능성을 말할 때
- ex: I'll probably stay home this weekend. | 이번 주말엔 아마 집에 있을 거예요.
- ex: It's probably the best option. | 아마 그게 최선일 거예요.
